# Proyecto U2: Tienda de Electrónica: inventario y ventas

Materia: Lenguajes de Interfaz, Unidad 2

Docente: Dr. José Luis Medina Jiménez

Integrantes:

- José Ángel Grande Espinoza
- Jesús Iván Martínez Reyes
- Ángel Ernesto Santos Plazola

Sistema de consola en MASM x86 de 32 bits con la biblioteca Irvine32 para una tienda de electrónica. Permite registrar hasta 10 productos, consultarlos y buscarlos por código, recibir mercancía, vender, ver un resumen de la sesión y guardar el catálogo en un archivo de texto para recuperarlo en otra ejecución.

## Compilación y ejecución

1. Clonar el repositorio:
   ```
   git clone https://github.com/IvanMartinez09/Proyecto-UNIDAD2.git
   ```
2. Abrir el archivo `.sln` que está dentro de la carpeta `TiendaElectronica`.
3. Verificar que la plataforma seleccionada sea **x86**.
4. Compilar con **Ctrl + Shift + B**.
